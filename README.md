# Doug Turnbull — academic portfolio

A single-page static website for the ICSM 105 VibeCoding 101 demo.

## Preview
Double-click `index.html` to open the site in your browser. No installation or build step is needed. Resize your browser to check the phone layout.

## Publish on GitHub Pages
1. Create a public repository. For a personal homepage, name it `YOUR-USERNAME.github.io`. A repository with another name also works.
2. Upload `index.html`, `style.css`, and the `images` and `fonts` folders, preserving the folder structure. The brief and README can also be included for the classroom demo.
3. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/ (root)** and save.
4. Visit the address GitHub displays when publication finishes.

Relative asset paths support both personal homepages and repository sites. Do not rename `style.css` without updating the stylesheet link in `index.html`.

## Edit
`brief.md` records the content, design decisions, sources, and research limitations. Edit visible content in `index.html`; change colors and layout in `style.css`. The portrait is stored in `images/doug-turnbull.jpg`. The `fonts` folder includes Figtree and Source Serif 4 and their licenses. Preserve it when uploading so the Ithaca College brand fonts load.

The page pairs recent work with the three most-cited papers in the Google Scholar text supplied by Doug on October 9, 2026. Citation counts are a static snapshot and must be updated manually. The colors and fonts follow the Ithaca College brand guide using its open-source font alternatives. External articles, slides, and papers may be moved or require access by their publishers.
